# 雙館展覽動線：實作與審查

起點：`4aba1a1`。需求來源：[museum-site.md](../specs/museum-site.md) 與使用者確認的雙館索引、攝影地圖開場。維持既有首頁，不恢復作品選集。

## 實作

- `/gallery` 只有短介紹與兩個同等入口；正常載入沒有作品 JSON 或 Leaflet 執行程式請求。既有全域 Leaflet 樣式仍會載入。
- 分類目錄改為必要參數 `[category]`，避免可選分類路由優先攔住新索引。展廳與活動網址維持不變，離場的同步 watcher 不得改寫索引。
- 地圖保留 A3 圓形照片、遠地 inset 與原互動；單一系列入場按鈕改用完整比例照片、既有敘事及清楚動作。
- 相機檔名式攝影展籤使用真實活動名與完整集合的穩定序號；網格、光桌、檢視器和替代文字一致。原始標題、ID、檔名及資料不改，網格展籤使用 computed lookup 避免游標移動時重算。
- 文章保留一份目次、真實已刊／編纂中狀態及正文日期；移除重複入口和固定本週新刊。
- 次要字級／對比與觸控整理；大圖放射導覽留在視窗內，手機縮圖 44px、中心按鈕 48px。分享連結等待掛載後才開大圖，避免 SSR hydration 不一致；query/hash 保留。

## 視覺驗證

第一批檢視桌機、平板、手機及明暗模式，包含雙館索引、系列入場卡、文章、活動光桌與大圖。冷讀設計審查確認索引導覽、系列卡原比例與文章減法可交付；桌機縮圖越界為唯一阻擋，已一次修正並確認。

1440×900 桌機縮圖最下緣 877.6px；390×844 手機最下緣 823.6px，均完整位於視窗內。暗色桌機的七張縮圖另以 `complete`／`naturalWidth` 確認載入；初次空圓截圖為取圖時序，不是失敗圖片。

既有六張畫廊矩陣與修改前比較：首屏差異集中在下緣入場卡（桌機 0.965%、平板 11.310%、手機 4.885%）；活動光桌 1.379% 主要在下緣展籤與片列。中段桌機 36.963%、手機 58.704% 包含入場卡高度增加造成的下方內容位移，不能當成全域樣式退化。

本機證據位於 `.tmp/museum-implementation/{before,after,diff,confirmation}`。此環境未提供規範提及的 Chrome DevTools MCP，使用獨立 headless Playwright 執行，沒有宣稱使用該 MCP。
